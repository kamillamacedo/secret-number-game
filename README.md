# 🎯 Secret Number Game

A simple interactive number guessing game built with JavaScript as part of my front-end learning journey.

## 🚀 About the Project

This project was developed during a course, but I took the time to understand the logic behind it and make small improvements on my own.

The goal is simple: the player must guess a randomly generated number within a defined range.

Along the way, the game provides feedback to guide the user until the correct number is found.

## 🧠 What I Practiced

- DOM manipulation
- Functions and conditionals
- User input handling
- Basic game logic
- State control (attempts, reset, etc.)

## ⚙️ Features

- Random number generation without repetition
- Attempt counter with dynamic feedback
- Reset game functionality
- Voice feedback using the Web Speech API
- Interface translated to English

## 🛠️ Technologies

- HTML
- CSS
- JavaScript

## 📌 Why This Project Matters to Me

This is my first JavaScript project, and an important step in moving from theory to practice.

Instead of just following the course instructions, I focused on understanding how everything works and making small customizations — which made the learning process much more meaningful.
